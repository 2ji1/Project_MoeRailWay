# 선로·열차 프로토타입 설계 브리핑

> **역사 문서 안내(2026-08-24):** 이 설계는 `prototype-m3`로 구현 완료된 연속 선로 기준입니다. 현재 격자 선로 정본은 `docs/superpowers/specs/2026-08-24-prototype-grid-track-amendment-design.md`이며, 사용자용 수정 요약은 `docs/briefings/ko/2026-08-24-prototype-grid-track-amendment-plan-briefing.md`입니다.

> 이 문서는 사용자 검토용 한국어 브리핑입니다. 에이전트가 실제 구현 기준으로 사용하는 영어 정본은 `docs/superpowers/specs/2026-08-16-prototype-track-train-design.md`입니다.

- 작성일: 2026-08-16
- 상태: 대화에서 승인된 설계
- 대상 마일스톤: `proto/02-track-train` / `prototype-m3`
- 구현 기준 브랜치: `Prototyping`
- 세션 경계: 이 대화에서는 문서와 계획만 작성하며 실제 Godot 개발은 별도 개발 세션에서 시작합니다.

## 1. 목표

이번 마일스톤은 제한된 선로를 먼저 예약하고, 실제 건설 속도와 후방 회수 속도를 계산하면서 멈추지 않는 열차를 유지하는 재미를 검증합니다.

핵심 변화는 다음과 같습니다.

- 초기 배치 선로를 제거합니다.
- 출차지점에서 선로를 예약하고 실제로 건설합니다.
- 완성 선로가 출차 기준에 도달해야 열차와 타이머가 시작됩니다.
- 예약 선로와 완성 선로를 분리합니다.
- 열차는 완성 선로만 달립니다.
- 예약 취소는 무료이고, 완성 선로 철거는 후속 유료 기능입니다.

## 2. 출차 준비

실행 직후에는 `출차 준비` 상태입니다.

- 세션 시간은 Inspector에서 설정한 전체 시간으로 보이지만 줄어들지 않습니다. 기본값은 3분입니다.
- 열차는 아직 운행에 투입되지 않았으므로 정지 상태로 취급하지 않습니다.
- 기본으로 8개 출차 후보를 배치하며, 세션 시드는 현재 배치된 전체 후보 집합에서 하나를 동일 확률로 선택합니다.
- 출차 후보는 `Marker2D` 노드이며 Godot 2D 에디터에서 피벗으로 직접 이동합니다.
- 같은 후보 구성과 같은 시드는 같은 후보 ID를 선택합니다.
- 재추첨이나 진행 가능성 보정은 없습니다.

실제로 완성된 선로가 Inspector에서 설정한 출차 요구 길이에 도달한 틱부터 열차와 타이머가 함께 진행됩니다. 기본값은 360단위이며, 별도 시작 버튼이나 추가 유예 시간은 없습니다.

## 3. 논리 필드

게임 거리는 화면 픽셀이 아니라 고정 논리 좌표를 사용합니다.

| 프리셋 | 논리 크기 |
|---|---:|
| `COMPACT` | `900 x 420` |
| `STANDARD` | `1200 x 560` |
| `EXPANSIVE` | `1500 x 700` |
| `CUSTOM` | Inspector에서 직접 입력 |

승인된 기본값은 `STANDARD`입니다. `CUSTOM`의 초기 허용 범위인 너비 640~4000단위와 높이 320~2160단위는 구현 계획용 잠정값이며 구현 전 검토할 수 있습니다. 이 범위는 승인된 세 프리셋을 모두 재현할 수 있습니다. 창 크기나 UI 패딩을 바꾸면 표시 배율만 변하고 열차 속도·선로 길이·재고·회수 거리는 변하지 않습니다.

프리셋 변경 시 출차 후보는 상대적인 배치 비율을 유지하며, 변경 후에도 각 노드를 에디터에서 다시 개별 이동할 수 있습니다. 논리 필드 루트는 현재 프리셋 또는 `CUSTOM` 크기의 경계를 Godot 2D 에디터에 표시하므로, 게임을 실행하지 않고도 후보 노드 피벗을 경계 안에서 배치할 수 있습니다.

## 4. 마우스 조작

### 좌클릭

좌클릭은 선로 그리기에만 사용합니다. 끝점 판정 24단위, 우클릭 판정 16단위, 최소 샘플 거리 8단위, 교차 전 여백 4단위는 모두 구현 계획용 잠정 튜닝 기본값이며 Inspector에서 조절합니다.

- 현재 예약 끝점 24단위 안에서 눌러야 그리기를 시작합니다.
- 누르는 동안 고정 틱마다 마우스 위치를 한 번 반영합니다.
- 끝점과 8단위 미만인 입력은 무시합니다.
- 버튼을 놓으면 입력만 끝나고 이미 예약된 선로 건설은 계속됩니다.
- 실제 건설이 뒤처져 있어도 예약 끝점에서 계속 추가로 그릴 수 있습니다.

### 우클릭

우클릭은 취소와 후속 철거에만 사용합니다.

- 예약·미건설 선로: 클릭 지점부터 예약 끝까지 무료 취소
- 완성·미주행 선로: `proto/04`에서 클릭 지점부터 앞쪽 끝까지 유료 철거
- 주행 완료 후방 선로: `proto/04`에서 후방 시작점부터 클릭 지점까지 유료 철거
- 열차가 점유한 지점과 빈 공간은 조작하지 않습니다.

우클릭은 누르는 순간 한 번만 처리하며, 계속 누르고 있어도 취소를 반복하지 않습니다. 우클릭하면 진행 중인 좌클릭 드래그가 끝납니다. 같은 틱에 좌·우클릭이 함께 들어오면 우클릭을 우선하며, 좌클릭을 계속 누른 상태로 자동 재개하지 않습니다. 새 예약 끝점에서 다시 그리려면 좌클릭을 놓은 뒤 새로 눌러야 합니다.

## 5. 예약과 실제 건설

선로를 드래그하면 유효 경로 길이가 즉시 재고에서 빠집니다. 실제 선로는 예약 경로를 순서대로 따라 건설됩니다. 아래 수치는 모두 Inspector에서 조절하는 승인된 기본값입니다.

- 전체 재고: 720단위
- 출차 요구 완성 길이: 360단위
- 실제 건설 속도: 초당 120단위, 기본 60틱에서 틱당 2단위
- 열차 속도: 초당 60단위, 기본 60틱에서 틱당 1단위
- 후방 유지 길이: 240단위, 기본 속도 기준 4초분
- 긴급 경고: 완성 선로 끝까지 3초 이하

재고는 항상 다음 식을 지킵니다.

`가용 재고 + 완성된 활성 선로 + 예약·미건설 선로 = 전체 재고`

예약은 즉시 차감하며 건설될 때 다시 차감하지 않습니다. 무료 취소나 자동 회수로 돌아온 길이는 정확히 한 번만 반환합니다.

## 6. 경계와 교차

새 예약 선로는 다음 중 가장 먼저 만나는 지점에서 잘립니다.

1. 남은 재고가 끝나는 지점
2. 논리 필드 경계
3. 완성 또는 예약된 활성 선로와의 자기교차 지점에서 잠정 기본 여백 4단위 전

필드 밖으로 드래그하면 경계까지만 예약하지만 드래그 상태는 유지합니다. 다시 안쪽으로 들어오면 경계의 끝점부터 계속 그릴 수 있습니다.

회수되거나 유료 철거된 선로 자리에는 다시 선로를 놓을 수 있습니다. `proto/02`에서는 활성 선로를 무료로 교차할 수 없습니다.

## 7. 열차·회수·종료

열차는 완성 선로만 달립니다. 예약 선로가 멀리 이어져 있어도 실제 건설 끝을 따라잡으면 `TRACK_END_REACHED`로 종료를 요청합니다.

열차 이동 후 240단위보다 뒤에 있는 선로는 부분 선분까지 연속적으로 회수합니다. 회수 재고는 그 틱 화면에 보이지만 다음 틱부터 새 예약에 사용할 수 있습니다.

정규 시간 만료와 선로 끝 도달이 같은 틱이면 사용자가 선택한 규칙대로 정규 시간 만료가 최종 사유입니다. 결과 화면은 정규 종료와 선로 끝 종료를 구분하고 한 번만 표시합니다.

## 8. Inspector 분리

밸런스 수치는 기능별 Resource에서 각각 조절합니다.

- `SessionBalance`: 세션 시간과 틱 수
- `TrainBalance`: 열차 속도
- `TrackInventoryBalance`: 전체 재고, 회수 거리, 경고 시간
- `TrackConstructionBalance`: 건설 속도, 끝점 판정 반경, 우클릭 판정 반경, 최소 샘플 거리, 교차 전 정지 여백
- `DepartureBalance`: 출차 요구 완성 길이
- `TrackInvestmentBalance`: `proto/04`의 철거·입체교차 공용 비용

기존 `PrototypeBalance`는 이 파일들을 참조해 시작값을 조합할 뿐 런타임 매니저가 되지 않습니다. 출차 후보 위치는 Resource 배열이 아니라 씬 노드로 유지합니다.

세션 시작 시 Inspector 값을 일반 값으로 복사합니다. 진행 중인 도메인은 Node나 Resource를 직접 참조하지 않으며, 실행 도중 Inspector를 바꿔도 현재 세션에는 영향을 주지 않습니다.

## 9. 화면 피드백

이번 범위에서는 최종 아트를 사용하지 않습니다.

- 완성 선로: 굵은 실선
- 예약 선로: 얇고 반투명한 선
- 건설 진행점: 작은 강조 마커
- 열차: 방향이 보이는 단순 도형
- 선택된 출차지점: 단순 마커
- `proto/02` 우클릭 대상: 예약 선로의 무료 취소 범위 강조
- 유료 철거 범위 미리보기: 철거 기능과 함께 `proto/04`에서 추가

상단 `TRACK`은 `가용 / 전체`를 표시합니다. 출차 준비 중 하단 `TRACK END`는 현재 Inspector 값을 사용해 `완성 / 출차 요구 길이`를 표시합니다. 운행 중에는 완성 선로 끝까지 남은 초를 표시하고, 설정된 긴급 경고 기준 이하에서 강조합니다.

## 10. 유료 철거와 입체교차

무료 예약 취소만 `proto/02`에 들어갑니다. 완성 선로 철거와 입체교차는 현금이 생긴 뒤 `proto/04-risk-investment`에서 함께 구현합니다.

- 완성·미주행: 클릭 지점 이후 전체 경로 철거
- 주행 완료 후방: 활성 후방 시작점부터 클릭 지점까지 조기 철거
- 두 철거와 입체교차는 하나의 `major_track_action_cost` 값을 공유
- 현금 부족 시 비용·경로·재고를 모두 변경하지 않음
- 철거 선로 길이는 재고로 한 번 반환하지만 현금은 돌려주지 않음
- 철거로 분기·합류·고립된 중간 선로를 만들지 않음

후방 유료 철거는 돈을 써서 선로를 일찍 돌려받는 투자 선택입니다. 기본 무료 방식은 계속 자동 회수이며, 같은 가격이 실제로 균형을 만드는지는 사용 빈도·조기 회수량·현금 압박을 플레이테스트로 검증합니다.

## 11. 검증 기준

자동 테스트에서는 다음을 확인합니다.

- 예약 차감과 무료 취소 반환
- 틱당 2단위 건설과 건설 중 추가 예약
- 출차 기준 360단위
- 경계·교차·재고 소진 절단
- 열차의 틱당 1단위 이동
- 부분 선분 회수와 중복 반환 방지
- 예약 선로가 남은 상태의 완성 선로 끝 종료
- 동일 시드 출차 후보 재현
- 후보 0개, 비어 있거나 중복된 ID, 필드 밖 후보 위치의 시작 거부
- 출차 준비 중 타이머 동결과 출차 임계 틱의 열차 1틱·타이머 1틱 동시 진행
- 비기본 밸런스값과 유효한 `CUSTOM` 필드가 코드 수정 없이 반영되는지 확인
- 잘못된 Resource·밸런스값·`CUSTOM` 크기가 소유자와 필드명을 알리며 시작을 거부하는지 확인
- 우클릭 한 번이 한 번만 취소하고 진행 중인 좌클릭 드래그를 종료하는지 확인
- 같은 틱 정규 종료 우선
- 최종 스냅샷 뒤 결과 한 번

Windows 수동 검증에서는 실제 좌·우클릭 감각, 세 가지 필드 프리셋과 `CUSTOM`, 에디터 논리 경계와 후보 피벗 정렬, 창 크기 변경, 출차 준비, 3분 운행 유지 가능성, 경고와 결과 화면을 확인합니다.

## 12. 범위 경계

이번 문서와 이어질 구현 계획은 `proto/02-track-train`만 다룹니다. 기능 브랜치와 Godot 코드는 사용자가 별도로 시작하는 개발 세션에서 생성합니다.

`Development`에는 프로토타입 이력을 통째로 병합하지 않습니다. 프로토타입 검증 후 본 개발에서 추상화 범위를 새로 결정하고, 검토된 규칙·데이터·순수 로직만 선택적으로 옮깁니다.
